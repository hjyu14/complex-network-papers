# 综述馆藏

`site/reviews.html` 是独立综述浏览页，复用 `app.js` 的文献卡片、主题和分页；`reviews.js` 负责全部历史年份的筛选。首页日期窗口、日更统计及 Spotlight 不变。

## 正式来源与生成

- `reports/reviews/pr-rmp-review-collection-2026-10-29/evidence/collection.json` 保存此前逐篇核验的 81 篇历史编辑选文及短说明，不代表整刊覆盖。原始登记、阅读事件和摘要版本哈希保留；完整摘要及原始工作文件仍仅保留私有目录。
- `config/review-collection.json` 明确钉住正式选集文件、数量和历史范围。没有扩充 `sources.json` 的每日白名单。
- `scripts/review_collection.py` 校验来源和逐记录哈希、书目、阅读范围与证据绑定。`publish_snapshot.py` 完成现有校验后附加生成 `site/data/reviews.json`；`--check` 同时校验此文件。新的类型或日期冲突必须明确解决，不能静默覆盖。
- `reviews.json` 仅收录已选定的历史选文。选中 DOI 若同时存在于 `papers.json`，复用同一条记录；其他近期综述不自动加入该选集。历史 DOI 若日后进入日更馆藏，构建先核对题名、作者、日期、说明和主题，相同则改为引用；不同则失败并等待显式核查。
- 当前选集为 84 篇（PR 72、RMP 12）：此前用户确认的 81 篇，加上本次经摘要审读及官网信息核验补入的 3 篇。补充来源保存于 `reports/reviews/pr-rmp-review-supplement-2026-10-29/`，由配置的 `supplemental_sources` 单独钉住，不改写原81篇来源；重复 DOI 直接报错。首页近期馆藏中的 Chaos 综述不属于此选集。跨页面重复出现的 DOI 不重复算馆藏。首页 271 篇近期文献与历史选集是不同浏览范围。
- 本次补核聚焦已登记资料中的缺 DOI、缺日期与未来卷期异常；不是重新完成两刊全历史官网覆盖。采用明确首次在线日期，未来卷期不覆盖已核验的在线发表日。逐项核对记录保留标题初筛、摘要审读和用户裁决的区别。

## 展示与维护

默认全部年份、按发表时间从新到旧；可按主题、期刊、年份及关键词组合筛选，并切换从旧到新。文章类型依据摘要推断时不冒称出版方标签；跨领域条目保留编辑选文属性，阅读说明明确仅依据摘要。

用户于2026-10-29核对本地预览后批准该版本提交、推送和上线，部署仍须核验。历史导入不计入日更新增，不更改当期荐读。未来 PR／RMP 的增量采集节奏另行确认。
