# NetSci Observatory：界面与方法标签实施记录

- 本轮改名、双语首页与规则页、每页十篇分页、可选折叠方法筛选。
- `site/data/papers.json` 和原收录审计不变，仍为 181 篇 v6 基线，日期范围不变。
- `scripts/annotate_methods.py` 为现有 DOI 重新读取 Crossref 标题和摘要，摘要只在内存中处理；任何请求失败均不替换标签文件。
- `site/data/methods.json` 保存独立的方法标签、证据短语、证据来自标题还是摘要，以及原快照与配置哈希。不改变论文收录决定。
- 前端接受 v6/v7 快照；v6 仅在标签文件与原快照匹配时加载新方法标签。没有标签不代表没有使用相关方法。
- AI 标签不由裸 `neural network` 触发，避免把生物神经元网络当成人工智能；`phase transition` 不单独证明理论方法，泛 `dataset` 不单独证明实证方法。
- 上轮简化样例测试不是实际论文回归验证。v7 收录规则仍需完整真实案例验证，尤其 Crossref 摘要缺失、APS 自身更正记录等问题；不得宣称已解决或已全量切换。
- 未修改 GitHub Actions、未推送或发布。重点区五刊名单保持不变，不将“及以上等级”解释为自动扩展重点期刊。
